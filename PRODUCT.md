# PRODUCT.md — Colores Dayam

## Vision & Purpose
**Colores Dayam** es un estudio profesional, intuitivo y de alto nivel para la creación, exploración, auditoría y exportación de sistemas de color y paletas semánticas adaptativas para aplicaciones web y móviles.

## Target Audience
- **Diseñadores UI/UX**: Que buscan armonías de color precisas, verificación de daltonismo y exportación directa de tokens de color.
- **Desarrolladores Web & Móviles**: Que necesitan tokens estructurados para Tailwind CSS, variables CSS y Capacitor / React Native.
- **Creadores & Artistas**: Que desean extraer paletas desde imágenes o generar temas completos mediante IA.

## Key Features
1. **Generador & Explorador de Paletas**: Creación en tiempo real con bloqueos, variaciones y armonías tipográficas.
2. **Paletas Semánticas & Previsualizador de Componentes**: Previsualización viva de componentes UI (botones, alertas, tarjetas, entradas).
3. **Auditoría de Accesibilidad & Daltonismo**: Simulación de acromatopsia, deuteranopia, protanopia y tritanopia con análisis de contraste WCAG AAA/AA.
4. **Generador con IA y Extracción de Imagen**: Generación contextual asistida por IA y extracción cromática desde archivos de imagen.
5. **Exportación Multi-formato**: Exportación instantánea a CSS, JSON, Tailwind CSS y formato nativo.

## Tone of Voice & UI Philosophy
- **Preciso y Técnico**: Información clara sobre valores HEX, RGB, HSL y ratios de contraste.
- **Estudio Creativo Vibrante**: La interfaz debe respirar color sin saturar; las superficies neutras deben tener matices sutiles.
- **Accesibilidad Extrema**: Enfoque *Accessibility First* tanto en móvil como en escritorio.
